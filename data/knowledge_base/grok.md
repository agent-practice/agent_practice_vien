# Grok (xAI)

## 개요
일론 머스크의 xAI가 개발한 LLM 패밀리. X(트위터) 플랫폼과 통합되어 실시간 소셜 데이터 접근성이 특징이며,
비교적 검열이 적고 직설적인 답변 스타일을 표방한다.

## 주요 모델 라인업 (일반 지식 기준 — 최신 라인업은 x.ai에서 확인 필요)
- **Grok (플래그십)** — 최고 성능 모델, 추론 강화 변형 포함.
- **Grok mini/경량 계열** — 저비용·저지연 변형.

## 특징
- X 플랫폼의 실시간 게시물 데이터에 접근 가능 — 최신 이슈에 대한 즉각적 응답에 강점.
- 이미지 생성 등 xAI의 다른 제품과 통합.
- X Premium 구독 및 별도 API로 제공.

## 가격 정책
X Premium/Premium+ 구독에 포함되거나, xAI API를 통한 별도 토큰당 과금.

## 적합한 용도
실시간 소셜/트렌드 데이터가 중요한 애플리케이션, X 플랫폼과 통합된 제품.

## 접근 방법
X(트위터) 앱 내 Grok, xAI API 직접 이용.

> 이 문서는 예시 시드 콘텐츠. 실제 배포된 최신 모델명·가격은 변동이 빠르므로 사용 전 공식 문서로 교차 확인 권장.
