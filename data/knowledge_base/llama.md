# Llama (Meta)

## 개요
Meta가 개발하는 오픈 웨이트(open-weight) LLM 패밀리. 상용 API로도 제공되지만, 가중치를 직접 내려받아
자체 인프라에서 구동할 수 있다는 점이 다른 상용 LLM과 가장 큰 차이.

## 주요 모델 라인업 (일반 지식 기준 — 최신 라인업은 llama.com에서 확인 필요)
- **Llama (대형, dense/MoE 변형)** — 최고 성능 라인. 대규모 추론 인프라가 있는 조직 대상.
- **Llama (경량 변형)** — 온디바이스·엣지 배포를 겨냥한 소형 모델.

## 특징
- 오픈 웨이트 라이선스(상업적 이용 조건부 허용)로 자체 호스팅, 파인튜닝, 온프레미스 배포가 가능.
- Meta AI 제품(WhatsApp, Instagram 등)과 Meta 클라우드 파트너(예: AWS, Azure, 각종 추론 호스팅 업체)를 통해서도 제공.
- 커뮤니티 생태계가 커서 파인튜닝된 변형·양자화 버전이 다양하게 존재.

## 가격 정책
자체 호스팅 시 인프라 비용만 발생(라이선스 비용 없음, 조건 충족 시). 서드파티 호스팅 서비스(예: 각종 추론 API 제공업체)를
이용할 경우 해당 업체의 토큰당 과금 정책을 따름.

## 적합한 용도
데이터 주권/온프레미스 요건이 있는 조직, 자체 파인튜닝이 필요한 도메인 특화 서비스, 오픈소스 생태계 활용이 중요한 프로젝트.

## 접근 방법
가중치 직접 다운로드 + 자체 호스팅, 또는 각종 클라우드/추론 API 제공업체(서드파티) 경유.

> 이 문서는 예시 시드 콘텐츠. 실제 배포된 최신 모델명·라이선스 조건은 변동이 빠르므로 사용 전 공식 문서로 교차 확인 권장.
