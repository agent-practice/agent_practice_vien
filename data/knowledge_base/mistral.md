# Mistral (Mistral AI)

## 개요
프랑스 Mistral AI가 개발하는 LLM 패밀리. 오픈 웨이트 모델과 상용 API 모델을 함께 제공하며,
유럽 데이터 주권(EU 데이터 레지던시)을 중요하게 여기는 고객층을 겨냥한다.

## 주요 모델 라인업 (일반 지식 기준 — 최신 라인업은 mistral.ai/technology에서 확인 필요)
- **Mistral Large 계열** — 최고 성능 상용 플래그십.
- **Mistral Small / 경량 계열** — 비용 효율적인 소형 모델, 오픈 웨이트로도 배포.
- **Codestral** — 코딩 특화 모델.

## 특징
- 오픈 웨이트와 상용(API 전용) 모델을 병행 제공 — 라이선스 유연성이 강점.
- 유럽 리전 호스팅/EU AI 규제 대응을 내세운 엔터프라이즈 포지셔닝.
- 함수 호출(tool use), JSON 모드 등 표준 에이전틱 기능 지원.

## 가격 정책
등급별(Large/Small/Codestral) 차등 과금. 오픈 웨이트 모델은 자체 호스팅 시 인프라 비용만 발생.

## 적합한 용도
EU 데이터 레지던시가 필요한 유럽 기업, 코딩 특화 워크로드(Codestral), 오픈 웨이트 자체 호스팅이 필요한 경우.

## 접근 방법
Mistral API 직접, Azure AI Foundry, Amazon Bedrock 등 파트너 클라우드를 통해서도 제공.

> 이 문서는 예시 시드 콘텐츠. 실제 배포된 최신 모델명·가격은 변동이 빠르므로 사용 전 공식 문서로 교차 확인 권장.
