# Gemini (Google)

## 개요
Google DeepMind가 개발한 멀티모달 LLM 패밀리. Google 생태계(검색, Workspace, Android)와 깊게 통합되어 있고,
네이티브 멀티모달(텍스트·이미지·오디오·비디오) 처리와 초장문 컨텍스트가 강점.

## 주요 모델 라인업 (일반 지식 기준 — 최신 라인업은 ai.google.dev/gemini-api/docs/models에서 확인 필요)
- **Gemini Pro 계열** — 범용 플래그십. 복잡한 추론, 코딩, 멀티모달 작업에 사용.
- **Gemini Flash 계열** — 속도·비용 최적화 버전. 대량 처리, 실시간 응답에 적합.
- **Gemini Flash-Lite / Nano** — 초경량 버전. 온디바이스 또는 초저지연 용도.

## 특징
- 매우 긴 컨텍스트 윈도우(수백만 토큰급)를 지원하는 모델이 있어 장문 문서·코드베이스 전체를 한 번에 처리하는 데 강점.
- 네이티브 멀티모달: 텍스트뿐 아니라 이미지·오디오·비디오 입력을 직접 처리.
- Google Search grounding(검색 연동)으로 최신 정보 기반 답변 지원.
- Vertex AI를 통해 엔터프라이즈 배포, 파인튜닝, 안전 필터 커스터마이징 가능.

## 가격 정책 (일반적 경향 — 정확한 수치는 공식 가격 페이지 확인)
Pro/Flash/Flash-Lite 등급별 차등 과금. Flash 계열은 대량 트래픽에서 비용 효율이 높은 편.

## 적합한 용도
초장문 컨텍스트가 필요한 작업(대규모 코드베이스 분석, 긴 문서 요약), 멀티모달 입력이 중심인 애플리케이션,
Google Workspace/Cloud 생태계와의 통합이 필요한 제품.

## 접근 방법
Google AI Studio / Gemini API 직접, Google Cloud Vertex AI를 통해 사용 가능.

> 이 문서는 예시 시드 콘텐츠. 실제 배포된 최신 모델명·가격은 변동이 빠르므로 사용 전 공식 문서로 교차 확인 권장.
